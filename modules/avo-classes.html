1Four corners of one plot

What the class names actually name

An AVO class is a position, not a rock. It says which quadrant of the intercept-gradient plane the top of a sand falls in, and that is decided jointly by the sand and by whatever sits above it. Class 3 is the familiar bright spot: negative intercept, negative gradient, getting brighter with offset. Class 1 is a hard sand under a soft seal, positive intercept and negative gradient, dimming and eventually reversing. Class 2 sits near the origin with almost no normal-incidence contrast. Class 4 has a negative intercept with a positive gradient, so it is bright at zero offset and dims away.

2Through the workflow

The same processing, four times

Each exemplar is now put through everything: partial stacks, picks, quadrant numbers, phase filters, the distance of module 05 and the angle of module 07. Nothing is tuned per class. The one thing that changes is the polarity flip — module 03 established that class 1 sands have both partial stacks reversed before picking, so that the top of the reservoir arrives at the picker as a trough like every other class.

3As histograms

How the papers summarise a volume

A section shows you where things are; a histogram tells you what the population looks like. The DQ papers pair the two, plotting the distribution of DQ values in an analysis window with the shale background, the wet sands and the gas sands marked as bands on the axis.

The scale matters. In a clastic section the great majority of samples are background shale sitting near zero, so on a linear count axis the interesting tail is invisible under a single enormous bar. A logarithmic count axis makes the tail readable. Untick the box in the panel to see what the linear version hides.

Read the separation figure across the four classes rather than for one. It compares the brighter sand samples, at the eightieth percentile, with the median of the whole window, because a median taken over the sand alone is dragged down by its quiet middle. It is largest where the intercept contrast is largest and smallest for class 2, which is the same ordering the sections show and the same one an interpreter would expect. The histogram is not adding information; it is making the population structure legible, which is what lets a delimiter or a polygon be placed sensibly on module 09's crossplot.

?Why classes are the wrong unit, and still useful

A caution and a defence

The class names are a convenience. A sand does not have a class; a sand under a particular seal at a particular depth has one, and the same reservoir can change class laterally as the overburden changes or vertically as compaction moves both trends. Module 01 showed one sand becoming class 1, 2 and 4 by changing only the rock above it.

They remain useful because they name the thing that decides how an amplitude method will behave. Knowing you are in a class 2 setting tells you the intercept is near zero and that anything depending on it will be fragile, which is worth knowing before you build a workflow on it. The DQ workflow does not remove that fragility. What it does is carry a second number, the angle, whose failure mode is different from the distance's, so that the two disagree in a detectable way rather than failing silently together.

The practical version, and the reason the papers cross-plot sliding time windows: watch the cluster. If it moves between windows, the class has changed, and any calibration tied to the old position no longer applies.

Exercises

  1. Read the four positions. On step 1, note the intercept and gradient of each exemplar.
    AnswerClass 1 has a positive intercept and a negative gradient, class 3 has both negative, class 4 has a negative intercept with a positive gradient, and class 2 sits near the origin. Those four sign combinations are the entire content of the classification. Note what that does not tell you: two sands in the same class can be quite different rocks, and the same rock changes class when the seal changes. A class is a statement about a boundary, so it is shared by every pair of rocks that happens to produce those signs. Everything else attached to the names — bright spot, dim spot, phase reversal — follows from where the line through those two numbers crosses zero.
  2. Find the polarity flip. On step 2, see which class has it applied.
    AnswerClass 1, because its intercept is positive and the reservoir top arrives as a peak rather than a trough. Troughs are Q1 and peaks Q9, so without the flip a class 1 top would be labeled Q9 while a class 3 top is Q1. Reversing both partial stacks before picking gives the same boundary the same label in every class.
  3. Compare the class 2 column with the others. On step 2, read the distance at the sand top for each class.
    AnswerClass 2 is much the smallest, because its intercept is close to zero by definition and the near stack is essentially the intercept. This is the same weakness module 07 met at its class 2 crossover and module 11 met under a soft shale: near a crossover the vector is short, the distance is small and the angle is unstable. It is a property of the rocks rather than of the method, and no processing removes it.
  4. Switch the histogram to a linear count axis. On step 3, untick the box.
    AnswerThe background bar near zero swamps everything and the tail vanishes. In a real clastic section the imbalance is far worse than in this model — the papers put it at roughly four samples in five being shale — which is why the published histograms use a logarithmic count axis. It is a display choice rather than a processing one, and it changes whether you can see the thing you are looking for.
  5. Thin the sand. Take the thickness to 10 ms and look at steps 2 and 3 together.
    AnswerEvery class loses separation at once, because module 11's tuning applies to all of them equally: the top and base reflections merge and the sand no longer has a sample of its own. The classes differ in how bright they are, not in how they respond to thinning, so a thin class 3 sand can read like a thick class 2 one. That ambiguity is exactly what module 11's pairing of distance with angle is for.
  6. Add noise and watch which class fails first. Take the noise to 30% on step 3.
    AnswerClass 2 degrades first and worst, because its separation was smallest to begin with and noise is added in absolute rather than relative terms. The ordering is the useful part: the class that is hardest in clean data is hardest in noisy data too, and by more. Any claim that a method works on class 2 should be demonstrated on noisy class 2 data rather than argued from clean models.

The main points

  • An AVO class is a position on the intercept-gradient plane, decided by the sand and the seal together, not a property of the reservoir.
  • All four classes are built from this one rock model by changing the seal, the fluid or the porosity.
  • The workflow is identical for all four, with one exception: class 1 has both partial stacks reversed before picking.
  • Class 2 is the hard case and stays hard. Its intercept is near zero, so the distance is small and the angle unstable.
  • The DQ pair does not remove that fragility; it makes it visible, because the distance and the angle fail differently.
  • Histograms summarise what a section cannot, and need a logarithmic count axis because most samples are background.
  • Separation ranks the same way in the histograms as in the sections, largest where the intercept contrast is largest.
  • Thinning costs every class equally, so a thin bright sand can read like a thick dull one.
Method, assumptions, and where to read more

The four exemplars are fixed recipes in the rock model used throughout this course, chosen so that each lands cleanly in one quadrant of the intercept-gradient plane: class 1 is a soft shale over a 10% porosity brine sand; class 2 a soft shale over a 34% brine sand; class 3 a soft shale over a 28% gas sand; class 4 a tight sandstone over a 26% gas sand. The class label shown on step 1 is computed from the signs of the modeled intercept and gradient rather than asserted, so if the rock model is ever retuned the labels follow it.

Everything downstream is as in modules 02 through 13, applied identically to all four. The one difference is the polarity flip of module 03, applied where the intercept is positive.

The histograms are of DQ distance over the whole analysis window, binned uniformly, with the samples falling inside the modeled sand marked separately. The logarithmic count axis follows the published displays; the note that roughly four samples in five are shale in a clastic section is from the DQ display specification and describes field data rather than this model, where the proportion depends on how thick you set the sand.

What this module does not do. It does not reproduce the published class sections, which are built from ray-traced synthetics over pseudo-well catalogs with lateral variation. It is four single traces from one rock model, intended to show what the class names mean and how the same workflow treats each. Comparisons between classes here are internally consistent; their absolute values are not calibrated to anything.
